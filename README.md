Python Task Manager OOP
A simple Task Manager built with Python to practise object-oriented programming (OOP), 
object interaction, task management, and input validation.
Features
1. Create Tasks: Create tasks with an ID, title, and priority.

2. Rename Tasks: Update task titles.

3. Complete Tasks: Mark tasks as completed.

4. Find Tasks: Search for tasks by ID.

5. Delete Tasks: Remove tasks by ID.

6. Filter by Status: View pending or completed tasks.

7. Filter by Priority: View tasks with Low, Medium, or High priority.

8. Priority Validation: Reject invalid priority values.

9. Error Handling: Handle invalid priorities using try and except.

Concepts Practised

1. Classes and objects

2. Constructors (__init__)

3. Instance attributes and methods

4. Lists and loops

5. Conditional statements

6. Returning values from methods

7. Exception handling (try, except, raise)

8. Input validation

9. Object-oriented design
